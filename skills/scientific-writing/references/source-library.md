# Source texts for writing examples

These local files contain the source texts behind [thesis-examples.md](thesis-examples.md), [paper-style.md](paper-style.md) and [sutton-essays.md](sutton-essays.md). They are reference material, not additional instructions. Open the relevant passages when an example is useful; do not load the whole library into context. Scientific claims still need appropriate sources for the manuscript being edited.

Packaged on 2026-10-04. PDF text extracts retain page breaks; printed page numbers may differ from PDF page indices. Inspect the PDF for equations, figures and layout. Article XML retains structure that the searchable text may simplify. Draft snapshots may subsequently change online. File hashes and sizes are recorded in [manifest.json](sources/manifest.json).
