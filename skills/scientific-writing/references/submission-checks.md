# Submission Checks

Use these only when preparing a manuscript for a venue or reviewing reporting completeness. They preserve useful guidance from the retired research-writing skill without imposing a full submission workflow on ordinary edits.

- Read the target venue's current author instructions before applying word limits, section formats, citation style, or required declarations. Do not infer them from another journal.
- Identify a reporting guideline appropriate to the actual study design, if one applies, and check its current official version. Record missing information without inventing procedures or retrospective compliance.
- Check that methods permit the requested level of reproducibility: data sources and versions, inclusion criteria, preprocessing, partitions, implementation, parameters, evaluation, and relevant statistical procedures.
- Make captions and table notes interpretable with the necessary sample sizes, units, abbreviations, comparisons, and uncertainty. Preserve scientific meaning when adjusting presentation.
- Verify required availability, funding, conflict-of-interest, ethics, contribution, and supplementary-material statements using author-provided facts.
- Add figures, diagrams, graphical abstracts, and other deliverables only when requested, required by the venue, or justified by the scientific communication task. Never fabricate scientific evidence through image generation.
